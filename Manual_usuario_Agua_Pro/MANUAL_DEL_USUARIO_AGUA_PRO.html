1. Introducción y Flujo de Trabajo

1.1 Objetivo del Sistema

Este sistema automatiza el diseño de conducciones de agua potable, permitiendo:

  • Extraer datos topográficos de perfiles desde AutoCAD Civil 3D
  • Calcular hidráulicamente la conducción en Excel
  • Dibujar automáticamente el perfil longitudinal en AutoCAD

1.2 Flujo de Trabajo Completo

┌─────────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  AutoCAD Civil 3D  │────▶│      Excel       │────▶│    AutoCAD      │
│                     │     │                  │     │                 │
│ 1. Dibujar eje y    │     │ 2. Calcular      │     │ 3. Dibujar      │
│    perfil vertical  │     │    hidráulico    │     │    perfil       │
└─────────────────────┘     └──────────────────┘     └─────────────────┘

1.3 Secuencia Operativa

Paso Aplicación Acción
1 AutoCAD Civil 3D Dibujar alineamiento horizontal y perfil vertical
2 AutoCAD Civil 3D Ejecutar comando PERFIL_PRO para exportar a Excel
3 Excel Ejecutar cálculos hidráulicos con macros VBA
4 Excel Ejecutar dibujo en AutoCAD

2. Exportación desde AutoCAD Civil 3D

2.1 Requisitos Previos

  • AutoCAD Civil 3D con Alineamiento y Perfil Vertical dibujados
  • Archivos en la carpeta del proyecto:
    • 1_ExportExcel.lsp (rutina LISP)
    • 1_procesar_perfil.py (script Python)

2.2 Ejecución del Comando

Paso 1: Cargar la rutina LISP

En AutoCAD, ejecutar:

(load "1_ExportExcel.lsp")

O simplemente escribir PERFIL_PRO - el sistema cargará automáticamente.

Paso 2: Seleccionar objetos

El sistema solicitará:

  1. Seleccionar el Alineamiento Horizontal
  2. Seleccionar el Perfil Vertical

Paso 3: Configurar diálogo

Aparecerá un diálogo con estos parámetros:

Campo Descripción Valor Típico
Nombre Proyecto Nombre identificador del proyecto (se sugiere automáticamente desde el nombre del alineamiento)
Intervalo (m) Distancia entre puntos de interpolación 10.0 m
Capa (m) Profundidad de enterramiento 0.80 m

Opciones de puntos geométricos:

  • ✅ Incluir PHIs - Puntos de inflexión horizontal (recomendado)
  • ⬜ Incluir PVIs - Puntos de inflexión vertical (opcional)
  • ✅ Incluir Extremos - Inicio y fin del alineamiento (recomendado)

2.3 Proceso de Exportación

El sistema:

  1. Extrae todas las abscisas y cotas del perfil
  2. Genera un archivo CSV temporal en Downloads
  3. Ejecuta el script Python para formatear datos
  4. Crea automáticamente las hojas necesarias en Excel:
    • Perfil Técnico: Datos crudos de topografía
    • calculo: Hoja de trabajo hidráulico

2.4 Resultado Esperado

Al finalizar, Excel contendrá:

  • Datos de topografía (abscisa, cota terreno, coordenadas UTM)
  • Estructura preparada para cálculos hidráulicos

2. Estructura de Archivos

2.1 1_ExportExcel.lsp

Este archivo contiene las siguientes funciones principales:

1_ExportExcel.lsp

├── get-prop-dual          → Lee propiedades con nombres alternativos

├── extraer-pvi            → Extrae PVIs del perfil vertical
├── C:PERFIL_PRO           → Comando principal
└── C:DIAG_SEG             → Diagnóstico de segmentos (debug)

2.2 Extracción de PHIs (Puntos de Inflexión Horizontal)

El sistema utiliza 4 métodos para extraer los PHIs del alineamiento:

Método Descripción Compatibilidad
M1 GetPICollection API Civil 3D ≥2010 Civil 3D moderno
M2 Colección Entities (StartingStation/EndingStation) Todos
M3 PassThroughPoint via DXF Civil 3D
M4 Unión entre segmentos Fallback general

Orden de ejecución: El sistema intenta M1 → M2 → M3 → M4 secuencialmente hasta encontrar resultados.

2.3 Extracción de PVIs (Puntos de Inflexión Vertical)

Extrae automáticamente del perfil vertical:

  • PVIs intermedios (excluye INICIO/FIN)
  • Numeración correlativa: PVi-1, PVi-2, etc.

El sistema solicita:

2. Seleccione el Perfil Vertical:

El sistema verifica que:

  1. El alineamiento sea de tipo correcto (contiene "ALIGNMENT")
  2. El perfil sea de tipo correcto (contiene "PROFILE" o "VALIGNMENT")
  3. Ambos objetos tengan rangos definidos (StartStation/EndStation)

Esto indica que el perfil tiene estaciones más allá del eje - revisar el diseño.

2. Ejecución de Cálculos

2.1 Método Principal: DatosFormulas

La macro principal DatosFormulas ejecuta todos los cálculos hidráulicos:

Sub DatosFormulas()
    ' Motor completo de cálculo hidráulico
    ' Calcula: pendientes, presiones, velocidades, pérdidas
End Sub

Qué hace esta macro:

  1. Limpia zonas de cálculo anteriores
  2. Verifica créditos del proyecto
  3. Aplica fórmulas a todas las columnas
  4. Calcula pendientes hidráulicas
  5. Genera resúmenes automáticos
  6. Aplica formato a accesorios

2.2 Orden de Ejecución

El flujo de cálculo es:

1. DatosFormulas
   ├── Limpia zonas de cálculo
   ├── Aplica fórmulas de pendientes
   ├── Calcula línea piezométrica
   ├── Determina presiones
   ├── Identifica válvulas automáticas
   ├── Genera resúmenes
   └── Aplica formato visual

El sistema genera automáticamente el perfil longitudinal completo en AutoCAD, incluyendo:

4. Pasos Elevados

4.1 Concepto

Un paso elevado (PE) permite cruzar una depresión (valle, quebrada) sin enterrar la tubería, manteniéndola a una altura fija sobre el terreno.

4.2 Marcaje de PE

El sistema utiliza un sistema de pares (INI/FIN):

Fila X:   PE-1 INI    ← Punto inicial
Fila Y:   PE-1 FIN    ← Punto final

4.3 Proceso de Creación

Paso 1: Marcar INICIO

  1. Posicionarse en la fila donde comienza el paso elevado
  2. Ejecutar macro PasoElevado
  3. El sistema marca PE-1 INI

Paso 2: Marcar FINAL

  1. Posicionarse en la fila donde termina el paso elevado
  2. Ejecutar macro PasoElevado
  3. El sistema marca PE-1 FIN y "aplana" el proyecto

4.4 Efecto del PE

Al marcar el punto FIN:

  1. Limpia la columna N (Cota Proyecto) entre INI y FIN
  2. Fuerza recalculo de fórmulas de forma relativa
  3. Resultado: La línea de proyecto se vuelve horizontal entre los dos puntos

4.5 Terreno Intocable

Importante: En los pasos elevados, el terreno (columna J) NO se modifica. Solo se ajusta la línea de proyecto para mantener la tubería sobre el terreno.

4.6 Numeración Múltiple

El sistema soporta múltiples pasos elevados:

  • PE-1 INI / PE-1 FIN
  • PE-2 INI / PE-2 FIN
  • PE-3 INI / PE-3 FIN

2 InterPol Aplicar Interpolación Inserta una fórmula de interpolación lineal en la celda activa basada en los valores vecinos (utilizado para perfiles y cotas interpoladas). Formula: =+interpolar(R[-1]C[-1],R[-1]C,R[1]C[-1],R[1]C,RC[-1])
3 TanqueRompePresion Insertar Tanque TRP Inserta una fila para un Tanque Rompe Presión (TRP), interpola la cota de terreno y reinicia la presión estática a cero en ese punto. Copia fórmulas del nodo anterior y marca como "TRP" en columnas AL y AP.
4 ValvulaReductoraPresion Insertar Válvula VRP Inserta una fila para una Válvula Reductora de Presión (VRP), solicita la presión requerida mediante InputBox y recalcula la línea piezométrica a partir de ese nodo.
5 PasoElevado Marcar Paso Elevado Configura un nodo como PE (Paso Elevado) en pares INI/FIN. El primer click marca "PE-X INI", el segundo marca "PE-X FIN" y "aplana" la línea de proyecto entre ambos puntos, interpolando una línea horizontal.
6 mensaje Validar Créditos Subrutina de control que verifica que la celda A16 contenga el texto "CREDITOS: Ing. Patricio Sarmiento Reinoso" como validación de autoría.
7 DatosFormulas Motor de Cálculo SUBRUTINA PRINCIPAL. Ejecuta el cálculo hidráulico completo aplicando fórmulas de velocidad, pérdidas de carga (Hazen-Williams) y presiones en bloque a toda la hoja. Incluye limpieza de zonas, aplicación de fórmulas por columnas, detección automática de VA/VP, formateo y resúmenes.
8 FormulasPline Exportar a AutoCAD Genera las cadenas de comandos PLINE para dibujar automáticamente el terreno (Columna I,J), la tubería (Columna I,P) y la piezométrica (Columna I,AJ) en AutoCAD. Escribe en columnas CN a CU.
9 AguaDatosDatPerfil Consolidar Perfil Copia y organiza todos los resultados de cálculo desde la hoja "calculo" hacia la hoja "PERFIL" para su visualización y posterior dibujo técnico. Copia rango H17:AL y AP17:AP.
10 MaxMinCalculo Estadísticas Globales Determina las elevaciones máximas/mínimas del terreno, proyecto y piezométrica, además de calcular la longitud total de la conducción y longitud inclinada total. Guarda estos valores en celdas S2-S7 y W2-W3 para configurar escalas del gráfico.
11 ResumenCalculo Resumen de Accesorios Escanea la conducción (columnas AL y AP) y genera una tabla con la ubicación (abscisa, cota), tipo y numeración correlativa de todas las válvulas (VA, VP), tanques (TRP), válvulas reductoras (VRP) y pasos elevados (PE). Escribe en columnas BA:BF.
12 Resumen3Calculo Resumen de Materiales Identifica los cambios de diámetro (Columna U) o caudal (Columna S) y calcula las longitudes de tubería por cada tramo específico. Genera descripción integrada "L= Xm DN=Ymm V=Z Q=W PN=N Serie=S". Escribe en columnas BZ:CL.
13 ResumenTotal Ejecutar Procesos Subrutina maestra que llama secuencialmente a Resumen3Calculo, ResumenCalculo y PendienteCalculada para ejecutar todos los resúmenes finales de forma coordinada.
14 DarFormatoAccesorios Formato Visual Aplica formato visual (negrita y color azul oscuro RGB 0,32,96) a las celdas de la columna AP que contengan etiquetas de accesorios (VA, VP, TRP, VRP, PE).
15 EliminarValvulasoTanques Eliminar Accesorio Elimina la fila del accesorio seleccionado, restaura la continuidad de fórmulas hidráulicas copiando desde la fila anterior y recalcula las pendientes. Validaciones: no elimina cabecera (filas <18) ni última fila.
16 CopiarDatosPerfil Importar Topografía Copia datos de topografía desde la hoja "Perfil Técnico" hacia la hoja "calculo" (columnas H, I, J). Lee desde fila 5 del Perfil Técnico.
17 LanzarFormulario Abrir Panel de Control Abre el formulario VBA "frmControl_CA" que serve como interfaz gráfica para ejecutar las principales operaciones del sistema.
18 InterpolarNuevaFilaAccesorio Motor de Interpolación Función avanzada de interpolación que: (1) carga abscisas en diccionario para búsqueda O(1), (2) busca coincidencia exacta, (3) inserta nueva fila si el punto está en rango, (4) calcula cota interpolada y (5) copia fórmulas del segmento.
19 InterpolarManual Interpolación Usuario Solicita al usuario la abscisa y nombre del punto a interpolar, luego ejecuta InterpolarNuevaFilaAccesorio y recalcula todo el sistema.
20 LimpiarVAlvulasVA_VP Limpiar Válvulas Elimina todas las válvulas automáticas (VA/VP) calculadas por el sistema, preservando los accesorios manuales (TRP, VRP, PE). Limpia columnas AM:AO y AP.

1.2 Funciones de Cálculo (UDF)

# Función Parámetros Propósito Técnico
1 calculav(Q, di) Caudal (l/s), Diámetro (mm) Calcula la velocidad real del flujo usando la fórmula V = Q/A. Convierte Q de l/s a m³/s y calcula área con di en metros. Retorna m/s.
2 LongInc(c1, c2, DH) Cota1, Cota2, Distancia Horizontal Calcula la Longitud Inclinada real de la tubería entre nodos considerando la diferencia de cotas. Fórmula: √((c1-c2)² + DH²)
3 PerdidaCarga(Q, L, C, D) Caudal, Longitud, Coef. C, Diámetro Calcula la pérdida por fricción usando la ecuación de Hazen-Williams completa: hf = 10.67 × L × Q^1.852 / (C^1.852 × D^4.87). Convierte Q a m³/s y D a metros.
4 Interpolar(x1, y1, x2, y2, x) Coord. X1,X2, Y1,Y2, X interpolado Realiza interpolaciones lineales exactas para cotas de terreno o piezométricas. Fórmula: y = y1 + (x-x1) × (y2-y1)/(x2-x1). Maneja división por cero.
5 pendiente1(x1, y1, x2, y2) Coordenadas 2D Calcula la pendiente porcentual entre dos puntos: (y1-y2)×100/(x1-x2). Retorna valor absoluto con signo según dirección.
6 SexToRad(grados) Ángulo sexagesimal Convierte ángulos en grados sexagesimales a radianes para funciones trigonométricas de VBA. Factor: π/180.
7 Nz(Valor) Valor variante Función de seguridad que trata celdas vacías o no numéricas como cero, evitando errores #¡VALOR! en cálculos.
